# Contributing to Snapline

Open a [bug report or feature request](https://github.com/pasariga/snapline/issues/new/choose). GitHub Issues is the contact channel for this Windows edition. English and simplified Chinese are welcome.

For a bug, include the Snapline version, Windows version, monitor scaling when relevant, and steps that reproduce it. Use sample images. Remove private paths, account names, screenshots and credentials before sharing diagnostics.

For a pull request, keep it focused, explain the user-visible change, and list the checks you ran. Follow [local development and isolated test instructions](LOCAL-DEVELOPMENT.md). Keep upstream copyright and font notices with the files you redistribute.

## 中文

欢迎用中文或英文在 [GitHub Issues](https://github.com/pasariga/snapline/issues/new/choose) 反馈。Bug 请附软件和 Windows 版本、复现步骤，涉及显示时请补充屏幕缩放比例。请使用示例图，分享诊断信息之前先去掉私人路径、账号、截图和凭据。

提交 PR 时，请说明用户能看到的变化和实际执行的验证。参考[开发与隔离测试说明](LOCAL-DEVELOPMENT.md)，并保留上游版权和字体授权。
